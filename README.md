# 🖥️ ServerPulse

Консольная утилита для **мониторинга состояния** серверов: **собирает** события (CPU, память, диск, задержки), **анализирует** их за период и **находит** проблемные узлы.

### 📑 Возможности

- Сбор и парсинг событий мониторинга (timestamp, server_id, cpu, memory, disk, latency)
- Фильтрация по серверу и региону
- Подсчет средних/макс/мин значений метрик
- Определение топ-N проблемных серверов
- Отслеживание превышения порогов CPU/памяти
- Расчёт перцентилей задержки
- Распределение инцидентов по статусам и регионам

### 🖱️ Использование

serverpulse analyze --from 2024-01-01 --to 2024-01-31 --server srv-01 --threshold-cpu 90

|CLI - команда|Функция|  
|------------|--------|
|analyze|анализ метрик за период|
|top|показать топ проблемных серверов|
|report|сформировать отчет по региону|

### 🗜️ Архитектура

> Система построена по принципу конвейра: события мониторинга проходят
> через фильтрацию по времени и серверу, затем агрегируются в метрики,
> после чего формируется список инцидентов и топ проблемных серверов.
>
> > Отдельно обрабатываются предупреждения ('include_warnings') -
> > они не считаются инцидентами, но учитываются в общей статистике.

```
[events] -> filter(time, server, region)
         -> aggregate(cpu, memory, disk, latency)
         -> detected_incidents(threshold_cpu, threshold_memory)
         -> top-n(problem_servers)
         -> { report }
```
